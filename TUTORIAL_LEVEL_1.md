# 🪟 Tutorial Level 1 Theme 1 - Window Cleaning Game

## Pengenalan Game

Selamat datang di **Window Cleaning Game**! Di game ini, kamu akan membersihkan jendela kotor dari berbagai tempat. Level 1 adalah level pemula yang akan mengajarkan mekanisme dasar game.

---

## 📊 Level 1 - HOME (Rumah)

### Informasi Level
- **Lokasi**: HOME (Rumah)
- **Kesulitan**: EASY
- **Target Waktu**: ~18-25 detik
- **Bintang Target**: ⭐⭐⭐ (untuk waktu cepat & tanpa kesalahan)

---

## 🎮 Mekanisme Dasar

### 1. **Jenis-jenis Alat Pembersih**

Ada 2 kategori utama alat:

#### 🌊 **Liquid Tools** (Alat Cair)
- **Water Bucket** (Ember Air)
- **Glass Cleaner** (Pembersih Kaca)
- **Cara Gunakan**: Tekan/tap pada noda untuk menyemprotkan

#### 🧹 **Wipe Tools** (Alat Usap)
- **Sponge** (Spons)
- **Squeegee** (Wiper)
- **Cara Gunakan**: Tarik/drag di atas noda untuk menghapus

---

## 🎯 Noda di Level 1

### Debu (Dust) - Spot 1 (Pertama)
```
Noda: Debu
Resep: Sponge
Durabilitas: 1x usap
Kesulitan: MUDAH
```

**Cara Membersihkan:**
1. Pastikan **Sponge** sudah dipilih (lihat di bawah UI)
2. **Tarik/drag** spons ke atas noda debu
3. Usap sampai noda hilang sepenuhnya
4. Noda akan berubah menjadi bersih ✓

### Air Mark (Bekas Air) - Spot 2 (Jika Ada)
```
Noda: Bekas Air
Resep: Glass Cleaner → Squeegee
Durabilitas: 2 tahap
```

**Cara Membersihkan:**
1. Pilih **Glass Cleaner** → Tap pada noda (semprotkan)
2. Tunggu beberapa saat (tidak perlu menunggu lama)
3. Pilih **Squeegee** → Tarik di atas noda
4. Tarik dengan gerakan konsisten dari atas ke bawah
5. Noda akan bersih ✓

## 🎮 Kontrol & UI

### Memilih Alat
- **Bagian Bawah Layar**: Pilihan alat tersedia
- **Tap Icon Alat**: Untuk menyeleksi alat yang ingin digunakan
- **Indikator**: Tool yang dipilih akan bersinar

### Mekanik Pembersihan

#### Saat Menggunakan Liquid (Cair)
```
Alur:
1. Pilih tool cair (Glass Cleaner, Water, dll)
2. Tap sekali pada noda
3. Efek visual akan muncul (gelembung/sempritan)
4. Tool berikutnya dalam resep akan terungkap
```

#### Saat Menggunakan Wipe (Usap)
```
Alur:
1. Pilih tool usap (Sponge, Squeegee, dll)
2. Drag/tarik di atas noda
3. Usap berulang kali sampai noda hilang
4. Akan ada efek partikel saat usap
5. Noda akan berubah warna (berkurang polusi)
```

## 📈 Indikator Kemajuan

### Progress Bar
- **Atas Layar**: Persentase total kemajuan level
- **Merah → Hijau**: Lebih banyak yang bersih = lebih hijau

### Status Noda
- **Warna Terang**: Noda masih butuh pembersihan
- **Badge di Noda**: Menunjukkan tool berikutnya yang dibutuhkan
- **Hilang Sepenuhnya**: Noda sudah bersih ✓

### Timer
- **Atas Kanan**: Waktu bermain (detik)
- **Target Waktu**: Tercantum di beginning hint
- **Semakin Cepat = Semakin Banyak Bintang**

## ⭐ Sistem Bintang

### Berapa Bintang yang Bisa Didapat?

**3 Bintang** ⭐⭐⭐
- Waktu: ≤ Target Waktu
- Kesalahan: ≤ 1 kesalahan

**2 Bintang** ⭐⭐
- Waktu: ≤ 1.5x Target Waktu
- Kesalahan: ≤ 3 kesalahan

**1 Bintang** ⭐
- Waktu: Lebih dari 1.5x Target Waktu
- Kesalahan: > 3 kesalahan

## 💡 Tips & Trik Level 1

### ✅ LAKUKAN INI:
1. **Pilih Alat yang Benar**
   - Setiap noda memberikan hint tentang tool yang diperlukan
   - Badge di noda menunjukkan tool berikutnya
   - Jangan sembarangan, akan kena mistake!

2. **Usap Dengan Konsisten**
   - Drag spons dengan perlahan dan stabil
   - Gunakan gerakan berulang untuk hasil lebih baik
   - Jangan berhenti sampai noda benar-benar hilang

3. **Perhatikan Visual Feedback**
   - Warna noda akan berkurang saat dibersihkan
   - Efek partikel menunjukkan progress
   - Suara "clean" = tahap selesai

4. **Manfaatkan Badge**
   - Badge putih di noda menunjukkan tool yang diminta
   - Ikuti petunjuk = tidak akan kesalahan

### ❌ JANGAN LAKUKAN INI:
1. **Menggunakan Tool Yang Salah**
   - Akan mendapat "Mistake" dan tier mood character marah
   - Karakter akan menunjukkan hint otomatis
   - Setiap mistake mengurangi score bintang

2. **Terburu-buru**
   - Gerakannya tidak akurat = tidak bersih
   - Perlu usapan yang tepat sasaran
   - Usap perlahan untuk hasil optimal

3. **Mengabaikan Hint/Petunjuk**
   - Hint menunjukkan tool yang dibutuhkan
   - Jangan asal pakai tool sembarangan
   - Pertimbangkan setiap langkah

## 📝 Kesalahan Umum & Solusi

### ❌ "Hmm… butuh Sponge"
**Masalah**: Menggunakan tool yang salah

**Solusi**: 
- Baca hint di bawah
- Lihat badge di noda
- Pilih tool yang benar
- Coba lagi

### ❌ Noda Tidak Hilang
**Masalah**: Usapan tidak cukup atau tidak akurat

**Solusi**:
- Usap lebih banyak
- Usap di atas noda, bukan di sekitarnya
- Gerakannya lebih perlahan dan konsisten
- Pastikan badgenya sudah di tahap usap (bukan tunggu)

### ❌ "Tunggu sampai busanya penuh..."
**Masalah**: Tool perlu waktu bekerja

**Solusi**:
- Tunggu lingkaran di noda penuh
- Ada animasi gelembung yang berputar
- Setelah penuh, baru bisa melanjutkan

### ❌ Waktu Terlalu Lama
**Masalah**: Terlalu banyak usapan / perencanaan kurang

**Solusi**:
- Usap dengan cepat tapi akurat
- Jangan terlalu sering bergerak
- Gunakan gerakan panjang bukan pendek-pendek
