# 🔐 Sistem Unlock - Skins & Themes

## Ringkasan Perubahan

Game sekarang memiliki sistem progression yang lebih challenging:
- ✅ **Skins**: Terkunci dan harus dibeli dengan koin
- ✅ **Themes**: Terkunci dan harus diselesaikan secara berurutan

---

## 🎮 SISTEM SKIN (Character)

### Status Awal
```
Owned: Cat (Gratis)
Locked: Semua skin lainnya
Coins: 0
```

### Harga Skin
| Tier | Skin | Harga |
|------|------|-------|
| **Murah** | Bunny, Puppy, Panda | 150 koin |
| **Standar** | Fox, Bear, Frog, Hamster | 200 koin |
| **Medium** | Mouse, Raccoon, Koala, Penguin | 250 koin |
| **Premium** | Duck, Chicken, Pig, Cow | 300 koin |
| **VIP** | Deer, Tiger, Lion, Monkey | 350 koin |
| **Ultra** | Red Panda, Otter, Capybara | 400 koin |
| **Langka** | Strawberry, Axolotl | 400-450 koin |
| **Legendaris** | Unicorn, Wizard, Robot, Alien | 500 koin |
| **Mythic** | Ghost, Witch, Astronaut | 600 koin |
| **Epic** | Baby Dragon | 750 koin |

### Cara Membeli Skin
1. **Mainkan Level** → Dapatkan Koin (reward berdasarkan bintang)
2. **Buka Skins Menu** → Lihat skin yang tersedia
3. **Klik Tombol BELI** → Jika koin cukup
4. **Pakai Skin** → Gunakan skin favorit

### Reward Koin per Level
```
1 Bintang  = 60 koin
2 Bintang  = 90 koin  
3 Bintang  = 120 koin
```

### Contoh Progress
```
Level 1 (3⭐)  → +120 koin  (Total: 120)
Level 2 (3⭐)  → +120 koin  (Total: 240)
Level 3 (2⭐)  → +90 koin   (Total: 330)
Level 4 (3⭐)  → +120 koin  (Total: 450)

Cukup untuk beli: Bunny (150), Puppy (150), Panda (150)
Atau: Fox (200), Bear (200), Frog (200) + 50 koin tersisa
```

## 🗺️ SISTEM TEMA (World Progression)

### Struktur Themes
```
Tema 1: HOME (Level 1-5)
  ├── Level 1: Dust, Water Mark
  ├── Level 2: Dust, Water Mark
  ├── Level 3: Dust, Water Mark
  ├── Level 4: Dust, Water Mark
  └── Level 5: Dust, Water Mark

Tema 2: CITY (Level 6-10) ⛔ LOCKED - Harus selesai Tema 1
  ├── Level 6-10: Dust, Water Mark, Mud
  
Tema 3: CAFE (Level 11-15) ⛔ LOCKED - Harus selesai Tema 2
  └── Level 11-15: Grease, Food Stain, Fingerprint, Dust

... (Dan seterusnya untuk 15 Tema)
```

### Cara Unlock Theme
```
1️⃣  Level 1 (HOME): TERSEDIA di awal
2️⃣  Selesaikan semua Level 1-5 dengan minimal 1⭐ setiap level
3️⃣  Unlock otomatis: Tema 2 (CITY) terbuka
4️⃣  Selesaikan Tema 2 (Level 6-10)
5️⃣  Tema 3 (CAFE) terbuka
... (Lanjut sampai Level 75)
```

### Visual Indicator
**Tema Unlocked** → Transparan penuh, bisa dimainkan
**Tema Locked** → Transparan 50% + Lock Icon + Pesan "Selesaikan tema sebelumnya"

```
┌─────────────────────────────────┐

├─────────────────────────────────┤
│ 🏘️ TEMA 2 - CITY               │
│ 🔒 LOCKED                       │
│ "Selesaikan tema sebelumnya"   │
└─────────────────────────────────┘
```

## 🎯 Strategi Optimal

### Early Game (Level 1-10)
```
💡 Tips:
1. Fokus selesaikan Level dengan 3⭐ (max coin)
2. Kumpulkan ~450-500 koin
3. Beli 2-3 skin murah (150-200)
4. Gunakan skin favorit untuk boost mood saat farming koin
```

### Mid Game (Level 11-40)
```
💡 Tips:
1. Naik tema setiap kali tema selesai
2. Koleksi skin medium (250-300) seiring koin bertambah
3. Jangan lupa farming 3⭐ di level mudah untuk koin
4. Bersiap untuk boss levels yang sulit
```

### Late Game (Level 41-75)
```
💡 Tips:
1. Sebagian besar skin sudah bisa dibeli
2. Fokus pada legendary & epic skins (500-750)
3. Challenge diri dengan level sulit untuk prestige
4. Unlock semua yang tersedia
```

## 📈 Earning Strategy

### Cara Maksimalkan Koin

**Method 1: 3-Star Farming**
```
Replay level mudah (1-5) dengan fokus 3⭐
Level 1 (3⭐) = 120 koin
Lakukan 5x = 600 koin (beli 3-4 skin murah)
```

**Method 2: Progress Normal**
```
Main level 1-75 dengan target 2⭐ minimum
Hasilkan koin saat progressing
Setiap level rata-rata 60-90 koin
```

**Method 3: Challenge Mix**
```
Main level baru untuk unlock tema
Replay level favorit yang mudah 3⭐
Kasih variasi sambil farm koin
```

## 🔧 Technical Details

### Data Tracking

**Progress.dart**
```dart
int unlockedLevel = 1;        // Level terbuka
int coins = 0;                // Koin player
List<String> ownedSkins = ['cat']; // Skin owned
String activeSkin = 'cat';    // Skin yang dipakai
Map<int, int> stars = {};     // Bintang per level
```

### Logic Unlock

**Level Unlock**
```dart
// Level baru unlock setelah level sebelumnya selesai
progress.unlockedLevel = max(unlockedLevel, levelCompleted + 1);

// Theme unlock setelah 5 level tema sebelumnya selesai
// Tema 1: Level 1-5
// Tema 2: Level 6-10 (unlock setelah Level 5)
// Tema N: Level 5N-1 hingga 5N
```

**Skin Owned**
```dart
// Hanya 'cat' owned awal
ownedSkins = ['cat'];

// Beli skin saat coins >= price
if (coins >= skinPrice) {
  coins -= skinPrice;
  ownedSkins.add(skinKey);
  activeSkin = skinKey;
}
```

## ✨ UI Changes

### Skins Screen
- Skin locked = Overlay gelap + Lock icon
- Price badge = Menunjukkan harga koin
- Button "BELI" = Jika punya cukup koin
- Button "BELI" disabled = Jika koin kurang
- Tooltip/Dialog = Notif "Koin tidak cukup" saat click

### Level Select Screen
- Theme terkunci = Opacity 50% + Lock icon
- Theme terbuka = Opacity 100% normal
- Sub-text = "Selesaikan tema sebelumnya" untuk locked
- Level terkunci = Bisa dilihat (masih dalam theme yang dibuka)
